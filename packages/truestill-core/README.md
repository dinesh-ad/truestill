# truestill-core

The core library behind [vaeon](https://github.com/dinesh-ad/vaeon): categorize, date,
de-duplicate and place media files into a stable `Category/YYYY/MM/` tree, targeting a
pluggable destination. Pure library - no CLI, no UI. See the repository root README for
the full picture.

Requires the `exiftool` binary on PATH (Ubuntu: `libimage-exiftool-perl`).

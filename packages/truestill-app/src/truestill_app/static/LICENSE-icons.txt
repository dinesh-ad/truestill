Nav icons in templates/index.html
=================================

Eight icons from Lucide (https://lucide.dev), inlined as SVG paths in
templates/index.html. Nothing is fetched at runtime and no icon library is a
dependency; only the path data is copied.

This notice ships BESIDE the icons it covers, in `static/`, for the same reason
LICENSE-DejaVu.txt does: `brand/` is not packaged, so a notice kept there would
not travel with the thing it licenses.

TWO LICENCES, NOT ONE, AND THAT IS WHY THIS IS PER ICON
-------------------------------------------------------
Lucide is ISC. But many Lucide icons are derived from Feather and remain MIT
under Cole Bemis's copyright, so a single blanket "ISC" line would be a licence
claim we could not support. Each icon below was checked against Feather's own
icon set on 2026-08-13; presence there means the MIT notice applies.

  icon                used for            origin              licence
  ----                --------            ------              -------
  map-pin             Trips & events      Feather-derived     MIT
  download            Import              Feather-derived     MIT
  hard-drive          Backups             Feather-derived     MIT
  search              Find                Feather-derived     MIT
  settings            Settings            Feather-derived     MIT
  chevron-left        collapse control    Feather-derived     MIT
  folder-input        Organize            Lucide original     ISC
  chart-column        Stats               Lucide original     ISC

Three more, added 2026-08-15 for the shadcn components, and inlined for exactly
the same reason as the eight above - `lucide-react` is not a dependency of this
project and adding one for three shapes is not a trade worth making. These live
in `frontend/src/components/ui/icons.tsx` rather than in the template, because
their callers are React; the provenance and the notice are unchanged. All three
were checked against Feather's own set on 2026-08-15.

  icon                used for            origin              licence
  ----                --------            ------              -------
  check               checkbox, select    Feather-derived     MIT
  chevron-down        select trigger      Feather-derived     MIT
  chevron-up          select scroll-up    Feather-derived     MIT

The radio-group indicator is a plain filled circle authored here, not copied
from any set, so it carries no third-party notice.

# truestill-app

The local web UI for [truestill](https://github.com/dinesh-ad/truestill): a Starlette server that
renders a browser front-end on `127.0.0.1`, calling `truestill-core` as a library. Start it with
`truestill-app`; it opens your browser at a token-authenticated localhost URL. `truestill-cli` remains
fully functional and co-equal.
